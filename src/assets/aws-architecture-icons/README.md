# AWS architecture icons

This directory contains the AWS service icons that the article diagrams use.

Source: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/)

Package release: July 31, 2026 (`Icon-package_07312026`)

The build embeds these files in self-contained SVG diagrams. Review the AWS icon package after each quarterly release. Replace an icon when AWS publishes a current version.

AWS permits customers and partners to use these assets in architecture diagrams and technical materials. AWS owns the icons and related trademarks.
